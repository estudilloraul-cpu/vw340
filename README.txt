Para GitHub Pages:
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. Activa GitHub Pages desde Settings > Pages.
3. Abre la URL una vez con conexión para que se guarden también las imágenes remotas.
4. En iPhone: Compartir > Añadir a pantalla de inicio.

La app guarda misiones, texto de bitácora y fotos únicamente en localStorage del dispositivo.
